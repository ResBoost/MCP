# Security

Please report security problems privately, not in a public issue: use
[**Report a vulnerability**](https://github.com/ResBoost/MCP/security/advisories/new) on this repo's Security tab.

Include what you found, where (URL or tool name), and how to reproduce it. We'll get back to you within 5 working days.

The server is read-only and serves public listing data only: nothing it returns isn't already on the listing pages at
[resboost.ai](https://resboost.ai).
